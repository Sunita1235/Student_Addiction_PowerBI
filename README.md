# Student_Addiction_PowerBI

An interactive Power BI dashboard to analyze student addiction data and present trends, patterns and insights.

---

## 📌 Project Overview
- Cleaned and transformed raw data using **Power Query**
- Built **data model relationships** between tables
- Created **DAX measures and calculated columns** for analytical reporting
- Designed an interactive dashboard with **KPI cards, slicers and drill-through**

## 🛠️ Tools & Concepts
Power BI Desktop · Power Query · Data Modeling · DAX · KPI Cards · Slicers · Drill-Through · Data Visualization
